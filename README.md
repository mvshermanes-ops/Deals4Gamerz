# Deals4Gamerz

Game-deal comparison website with search, currency conversion, platform filters and direct offer links.

## Run locally
npm install
npm start

Open http://localhost:3000

## Deployment
This repository includes render.yaml for a Node/Express Render web service.

## Data
The current prototype uses the public CheapShark deal API and ExchangeRate-API open endpoint. Before commercial launch, verify current provider terms, region accuracy, attribution requirements and add official/affiliate feeds where appropriate.
